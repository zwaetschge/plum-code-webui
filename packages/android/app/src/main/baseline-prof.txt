# Hand-authored baseline profile for Plum Code (Android).
#
# AGP 8.x compiles src/main/baseline-prof.txt into the APK/AAB automatically;
# androidx.profileinstaller writes it into ART's profile directory on first
# launch so the cold-start and chat paths are AOT-compiled before the
# device has collected any JIT samples of its own.
#
# H = hot, S = startup, P = post-startup. Method rules use `->name(args)ret`,
# class rules end with `;`. Wildcards keep the file valid across refactors;
# `Lcom/claudewebui/app/**;` pre-verifies every app class so class loading
# on the main thread does not stall on verification.
#
# Regenerate with a Macrobenchmark once one exists; until then keep this in
# sync with the cold-start path: Application -> Koin -> MainActivity ->
# navigation -> dashboard -> chat.
