Plum Browser

Lässt deine Plum-Code-Agents diesen Browser steuern – jede Session in ihrem eigenen Fenster mit Tab-Gruppe.

Verbindung

…

Die Adresse deiner Plum-WebUI. Hinter Authelia/SSO wird automatisch der /mobile-Zugang verwendet.

In Plum unter Settings → Browser control → Pair browser erzeugen. Der Token erlaubt nur die Browser-Steuerung, keinen API-Zugriff.

Sicherheit

Steuerung pausieren Agents bekommen eine Fehlermeldung, bis du fortsetzt.
JavaScript-Ausführung erlauben Werkzeug evaluate_js: Agents können Code in Seiten der Tab-Gruppe ausführen.

Eine Adresse pro Zeile, * als Platzhalter (*bank*, paypal.com gilt auch für Subdomains). Hier fragt der Agent auf der Seite nach, bevor er klickt, tippt, navigiert oder Dateien hochlädt.

Agents sehen und steuern nur Tabs in der Tab-Gruppe ihrer Session („Plum · …“). Ziehe einen Tab in eine Gruppe, um ihn freizugeben; schließe die Gruppe, um den Zugriff zu beenden. Beim Arbeiten zeigt der Tab einen violetten Rahmen.
